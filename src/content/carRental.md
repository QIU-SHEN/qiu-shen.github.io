# 汽车租赁管理系统

## 1. 项目概述

汽车租赁管理系统是一套面向汽车租赁企业及门店管理人员的前后端分离业务平台。系统围绕“车辆入库—客户登记—车辆出租—车辆归还—费用结算—经营统计”构建完整业务闭环，并覆盖保养提醒、违章处理、订单管理、押金返还和权限管理等场景，实现租赁业务全流程数字化管理。

平台将车辆状态、客户资料、租赁订单和财务数据统一管理，减少人工登记、重复录入和跨部门核对成本，为日常运营、财务统计和管理决策提供可靠的数据支持。

## 2. 技术栈

| 分类 | 技术 |
| --- | --- |
| 前端 | Vue 2、Vue Router、Vuex、Element UI、Axios、ECharts |
| 后端 | Java 17、Spring Boot 3、Spring Security、MyBatis-Plus |
| 数据与缓存 | MySQL、Redis |
| 数据处理 | Fastjson2、Hutool、EasyExcel |
| 文件与消息 | 阿里云 OSS、Spring Scheduling、JavaMail |
| 工程工具 | Maven、Git、Swagger / OpenAPI |

### 系统架构

```text
Vue + Element UI 管理端
        │  Axios / JSON / JWT
        ▼
Spring Boot REST API
Controller → Service → Mapper → Entity
        │                         │
        ▼                         ▼
MySQL 业务数据                Redis 登录令牌
        │
        ├── 阿里云 OSS：车辆图片
        ├── EasyExcel：业务报表
        └── JavaMail：经营日报
```

前端负责页面展示、表单校验、动态路由和接口调用；后端采用分层架构处理业务逻辑，通过 MyBatis-Plus 访问 MySQL，并使用 Spring Security、JWT 与 Redis 构建无状态认证体系。登录成功后，系统根据用户角色和权限生成可访问菜单，实现页面级与按钮级权限控制。

## 3. 核心业务

| 功能模块 | 主要内容 |
| --- | --- |
| 车辆档案 | 维护车辆厂商、品牌、车牌、车型、颜色、排量、里程、日租金、押金、图片、上牌日期及车辆状态，支持组合查询、新增、修改、逻辑删除和批量操作。 |
| 客户管理 | 管理客户姓名、身份证号、年龄、性别、联系电话及出生日期，为租车登记、订单查询和历史追溯提供客户档案。 |
| 租赁业务 | 按条件筛选可租车辆，登记客户、租赁类型、租金、押金和起租里程，生成租赁订单并同步更新车辆状态。 |
| 归还与订单 | 查询未完成订单，登记归还时间与里程，核算应收与实收租金，处理押金返还并查看历史订单详情。 |
| 保养管理 | 记录车辆保养时间、项目、地点和费用，结合车辆里程提供保养提醒。 |
| 违章管理 | 记录违章车辆、时间、地点、事由、扣分、罚款和处理状态，并关联订单进行核查。 |
| 财务统计 | 统计日租赁量、日归还量、月度订单、应收租金、实收租金及押金收入，通过图表展示经营趋势。 |
| 系统管理 | 管理用户、部门、角色、菜单与权限，支持角色授权、用户绑定角色、树形部门/菜单以及动态路由。 |

### 业务流程

```text
维护车辆与租赁类型 → 登记客户 → 选择可租车辆 → 创建订单
        → 车辆归还与费用结算 → 押金返还 → 保养/违章处理
        → 财务统计 → 自动生成并发送经营日报
```

## 4. 核心技术实现与个人职责

### 后端工程架构

负责基于 Spring Boot 3 搭建后端服务架构，按照 Controller、Service、Mapper、Entity 划分职责，并实现统一接口响应、全局异常处理、字段自动填充和逻辑删除机制，降低模块耦合度，提升代码可维护性。

引入 MyBatis-Plus 优化数据库访问，利用通用 CRUD、分页查询、条件构造器和代码生成能力减少重复代码；复杂经营统计通过自定义 Mapper 与 MySQL 聚合查询实现。使用 Maven 统一管理依赖版本、插件和构建生命周期，使项目的编译、测试、打包与运行流程标准化。

### 身份认证与权限控制

基于 Spring Security、JWT 与 Redis 构建无状态认证体系。通过自定义过滤器完成 Token 提取、Redis 有效性校验、用户身份解析及安全上下文注入，并结合角色、菜单和按钮权限控制前端动态路由，满足前后端分离架构下的登录认证与访问授权需求。

### 数据交换与通用能力

基于 Fastjson2 完成登录信息、权限数据和接口业务对象的序列化与反序列化，简化前后端数据交换及复杂对象转换；结合 Hutool 封装日期、字符串、文件和集合等常用操作，减少重复工具代码。

### 经营分析看板

基于 ECharts 与 MySQL 聚合查询构建经营分析看板，统计日租赁量、日归还量、月度订单、应收租金、实收租金及押金收入，并通过折线图、柱状图等形式展示经营趋势，为业务分析和经营决策提供直观依据。

### 报表导出与云端存储

基于 Hutool Excel 与 EasyExcel 实现业务报表导出，将车辆资料和经营数据生成 Excel 文件并通过浏览器下载，为财务核对、运营分析和线下归档提供支持。

基于阿里云 OSS 实现车辆图片云端存储，完成图片上传、访问和删除流程，降低本地文件存储压力，并提升静态资源访问效率和管理能力。

### 自动经营汇报

基于 Spring Scheduling 与 JavaMail 实现自动经营汇报。计划任务按日汇总租金及押金收入，生成经营日报并自动发送至指定邮箱，减少人工统计和重复汇报成本。

### 前端管理界面

基于 Vue 与 Element UI 构建后台管理界面，完成车辆、客户、订单、保养、违章、财务和权限模块页面，并通过 Axios 与后端 RESTful API 交互。通过请求拦截器统一携带 Token，根据后端权限菜单动态注册路由，实现界面、数据与权限状态联动。

## 5. 项目亮点

1. **业务流程完整**：覆盖车辆档案、出租、归还、押金、保养、违章和财务统计，形成汽车租赁业务闭环。
2. **认证体系清晰**：通过 Spring Security、JWT 与 Redis 完成无状态认证，并支持角色、菜单和按钮级权限控制。
3. **经营数据可视化**：将订单和财务聚合结果转化为经营看板，帮助管理人员快速掌握业务变化。
4. **运营流程自动化**：整合 Excel 报表、OSS 图片管理和邮件日报，减少人工处理与线下传递成本。
5. **工程结构规范**：前后端职责清晰，后端统一响应与异常处理，依赖和构建流程由 Maven 统一管理，便于后续维护和扩展。
