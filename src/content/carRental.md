# 汽车租赁管理系统——项目介绍

## 1. 项目概述

汽车租赁管理系统是一套面向汽车租赁门店及管理人员的前后端分离式后台管理平台。系统围绕“车辆入库—客户登记—车辆出租—车辆归还—违章/保养处理—经营统计”这一业务闭环展开，并提供用户、角色、权限和部门管理能力，目标是将车辆状态、租赁订单和客户资料统一管理，减少人工登记与信息重复维护，提高门店运营效率。

目前项目已完成前后端基础框架、登录鉴权、动态菜单、统一响应及多类管理页面，车辆厂商、品牌、部门、菜单权限等部分接口已经实现；车辆、客户、订单、保养、违章与财务统计等业务接口仍在持续完善。本文按照系统的完整设计范围进行介绍。

### 系统架构

```text
Vue 2 + Element UI 前端
        │  Axios / JSON / Token
        ▼
Spring Boot REST API（Controller → Service → Mapper）
        │                         │
        ▼                         ▼
MySQL 业务数据                Redis 登录令牌
```

系统前端负责页面展示、表单校验、动态路由和接口调用；后端采用分层架构处理业务逻辑，通过 MyBatis-Plus 访问 MySQL，并使用 Spring Security、JWT 与 Redis 构建无状态认证机制。登录成功后，系统根据用户角色与权限生成可访问菜单，实现页面级和按钮级权限控制。

## 2. 主要功能

| 功能模块 | 主要内容 |
| --- | --- |
| 车辆档案 | 维护车辆厂商、品牌、车牌、车型、颜色、排量、里程、日租金、押金、图片、上牌日期及车辆状态，支持条件查询、新增、修改、删除和批量操作。 |
| 客户管理 | 管理客户姓名、身份证号、年龄、性别、联系电话及出生日期，为租车登记和订单查询提供客户档案。 |
| 租赁业务 | 按车辆条件筛选可租车辆，登记客户、租赁类型、租金、押金和起租里程，生成租赁订单。 |
| 归还与订单 | 查询未完成订单，登记归还时间与里程，计算应付/实付租金，处理押金退还，并查看历史订单详情。 |
| 保养管理 | 记录车辆保养时间、项目、地点和费用，结合车辆里程辅助识别待保养车辆。 |
| 违章管理 | 记录违章车辆、时间、地点、事由、扣分、罚款和处理状态，并可关联订单进行核查。 |
| 财务统计 | 按日、按月统计出租、归还及经营成本数据，并预留图表化经营分析能力。 |
| 系统管理 | 管理用户、部门、角色、菜单与权限；支持角色授权、用户绑定角色、树形部门/菜单以及动态路由。 |

### 业务流程

```text
维护车辆与租赁类型 → 登记客户 → 选择可租车辆 → 创建订单
        → 车辆归还与费用结算 → 押金处理 → 保养/违章记录 → 财务统计
```

## 3. 技术栈与项目特点

### 后端技术

- **Java 17、Spring Boot 3.0.10**：搭建 RESTful 后端服务，默认运行端口为 `8888`。
- **Spring Security + JWT + Redis**：完成登录认证、Token 校验、退出登录和无状态会话管理；密码使用 BCrypt 加密。
- **MyBatis-Plus 3.5.5 + MySQL 8.0**：实现数据持久化、分页查询、逻辑删除、字段自动填充及代码生成；复杂查询使用 XML Mapper。
- **Fastjson2、Hutool**：用于 JSON 处理、JWT 与常用工具能力；统一通过 `Result<T>` 返回接口结果。
- **Aliyun OSS、EasyExcel、Pinyin4j**：分别支持车辆图片等文件存储、Excel 数据导入导出以及名称拼音排序等扩展能力。
- **Springfox Swagger、Lombok、Maven**：用于接口文档、简化实体代码以及依赖和项目构建管理。

### 前端技术

前端项目位于 `E:\java\汽车租赁管理系统\源代码\vue-element-admin-master`，基于 **Vue 2.6、Vue Router、Vuex、Element UI、Axios** 和 vue-element-admin 搭建，默认开发端口为 `9527`。系统通过 Axios 拦截器自动携带 Token，并根据后端返回的权限菜单动态注册路由；同时使用 **ECharts** 展示统计图表，使用 **xlsx / file-saver** 支持表格导出。前端已提供车辆、客户、租赁、归还、订单、保养、违章、财务及系统管理页面。

### 项目特点

1. **业务闭环清晰**：从车辆档案到出租、归还、押金、保养和违章，覆盖租赁门店的主要工作流程。
2. **权限控制灵活**：用户、角色、菜单、按钮权限相互关联，后端返回菜单树，前端按权限动态生成路由。
3. **工程结构规范**：后端采用 Controller、Service、Mapper、Entity 分层，前端按 views、api、store、router 模块化组织，便于继续扩展。
4. **数据管理友好**：支持分页、组合查询、批量操作、逻辑删除、Excel 导出和图表统计，适合后台管理场景。
