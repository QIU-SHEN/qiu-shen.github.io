# 欢迎来到我的笔记

这里是 QIUSHEN 的笔记区，记录一些前端学习路上的零碎想法和总结。

## 这些笔记是怎么来的

这些笔记是**内置在站点里的静态 Markdown 文件**，没有后端、也没有数据库。

- 每篇笔记就是 `src/notes/` 目录下的一个 `.md` 文件
- 想加一篇，就新建一个 `.md`，写好开头的 frontmatter（标题、标签、日期）即可
- 站点构建时会自动把它们打包进来

## 写法示例

```markdown
---
title: 我的新笔记
tags: Vue, 学习
date: 2026-06-26
---

# 正文标题

随便写点 Markdown……
```

## 支持的内容

正文支持常见的 Markdown 语法：标题、列表、**加粗**、`行内代码`、代码块、引用、表格、链接等。

> 右侧的悬浮目录会根据正文里的标题自动生成，点一下可以跳转。

慢慢来，享受记录的过程吧。
