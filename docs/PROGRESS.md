## 关键决策记录
- 首页跳转入口只保留文字，不使用卡片、图标、说明或操作提示。
- 顶部导航使用 `Project` 进入 `/Project`；个人介绍仅由首页“关于我”入口进入 `/About`。
- `/Project` 保留原三张 3D 旋转卡片体验，仅将卡片详情链接更新为新的项目路由；移动端继续使用静态纵向卡片。
- AI 助手通过同域 `/api/chat` 调用 Vercel Function，DeepSeek Key 只存在于服务端环境变量。
- Vercel 使用 SPA 回退规则支持深层路由直接访问，生产别名固定为 `personal-webpage-five-gules.vercel.app`。
- Project 轮播的深浅主题图片统一使用 `/dark1.png`、`/light1.png` 等站点根路径，避免嵌套路由下解析到错误目录。
- GitHub Pages 使用独立构建变量关闭 AI 助手并启用 Hash 路由，不影响 Vercel 的 AI 版本。
- 保留原有路由与点击行为，移动端和桌面端使用同一种轻量结构。
- “关于我”正文以 `src/content/profile.md` 为唯一内容来源，通过现有 Markdown 组件在 `/About` 渲染，不参与笔记目录扫描。
- 笔记标签使用主题色紧凑样式；列表页与详情页侧栏保持同一结构，触屏点击不保留悬停状态。
- 笔记详情页在 `1600px` 以上启用 `980px / 18px` 居中阅读栏，笔记本与手机布局保持原样。
- 笔记图片统一存放在 `public/notes/` 并使用站点绝对路径，避免依赖桌面本地目录。
- 笔记目录按标题层级自动分组，箭头控制折叠，标题文字继续负责正文跳转。
- 每篇技术学习笔记使用独立的 `public/notes/<slug>/` 图片目录，避免资源重名和本地路径依赖。
- 音乐播放器采用单一 `<audio>` 实例；关闭全屏界面时只切换为迷你态，不销毁或复制音频实例。
- 播放器全局挂载，切换站内路由后继续播放。
- 悬浮球提供恢复全屏、播放 / 暂停和真正停止三个操作。
- 移动端悬浮球与现有任务按钮纵向错开。
- 音乐资源统一使用 `public/` 根路径，确保构建后和跨路由场景下地址稳定。
- 音乐悬浮球已完成开发，并通过生产构建和桌面 / 移动端浏览器自动化回归。
- 笔记页采用个人编辑式阅读布局，减少面板、边框和图标，粉色仅用于链接、当前目录和细节强调。
- 文章标题由页面头部统一展示；与元数据同名的 Markdown 首标题及其后的初始分隔标记仅在渲染时隐藏，不修改原始笔记。
- 笔记加载或切换后，右侧目录中所有包含子标题的分组默认折叠，用户仍可通过箭头逐级展开。
- 笔记标题下方的元信息按“日期、字数、阅读时长、标签”排列，字数使用千位分隔。
- 自定义字体使用相对 `src/style.css` 的资源地址交由 Vite 打包，避免在嵌套路由下解析为错误路径。
- AI 销售陪练与汽车租赁项目分别使用 `/Project/ai-sales-coach` 和 `/Project/car-rental`，不再复用个人介绍命名。
- 项目正文分别存放在 `src/content/aiSalesCoach.md` 与 `src/content/carRental.md`；AI 销售陪练截图位于 `public/project/ai-sales-coach/`。
